# 五节实践课

1. **请求生命周期**：从 server.js 读到 createApp，使用 curl 观察状态码、Location 和 X-Request-ID。
2. **输入边界**：提交空标题、错误布尔值和未知字段，解释为什么错误返回 400 而不是默默修正。
3. **分离业务与存储**：比较内存模式与 DATA_FILE 模式，确认 HTTP 调用方式不变。重启后检查数据保留差异。
4. **异步错误**：阅读测试中故意抛错的仓库，确认 Express 5 转入错误中间件，且客户端不会看到内部错误字符串。
5. **扩展一个需求**：为任务增加 priority 字段，先写边界测试，再更新契约、服务与存储格式。讨论旧文件迁移，不能只修改前端显示。

完成标准：能够独立运行增删改查；错误有稳定 code；测试不依赖真实数据库；停止服务时存储锁正常释放。
